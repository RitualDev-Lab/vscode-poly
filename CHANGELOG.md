# Changelog

All notable changes to **Poly for VS Code / Cursor** (`ritualdev-lab.vscode-poly`) are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added
- Embedded animated extension workflow preview (`media/demo.gif`) in `README.md`.
- Editor right-click context menu actions for manifest files (`poly.toml`, `package.json`, `pyproject.toml`, `Cargo.toml`, `go.mod`).
- Keyboard shortcuts (`Ctrl+Alt+P A`, `Ctrl+Alt+P F`, `Ctrl+Alt+P V`, `Ctrl+Alt+P I` / `Cmd+Alt+P ...` on macOS).
